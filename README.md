# Filzat-Metals

Filizat Metals is a multi-generational metallurgical sourcing aggregator and global logistics platform, connecting traditional casting foundry operations in Aligarh, India to international manufacturers.

## Features

- Rebranded base metals and hardware alloys sourcing.
- Built using Vite, React, Tailwind CSS, and TanStack Router.
- Premium interactive scroll animations with Framer Motion.
- RoHS & REACH environmental compliance tracking.
- SG, Bureau Veritas, and Intertek third-party audit openness.
